# نشر الدروس على شارف

نُقل قالب الدرس النهائي إلى واجهة الموقع الأصلية، دون استبدال صفحات الموقع أو القائمة الجانبية أو الخادم. الدرس المنشور الأول: `l-mm6el08l` (زوايا المضلع).

## إضافة درس

1. أضف اسم الدرس ومعرّفه في هيكل الموقع من لوحة التحكم، دون تغيير معرّفات الدروس الحالية.
2. أنشئ تعريفًا في `shared/lesson-engine/` مطابقًا للمعرّف، يتضمن اسم الدرس والأهداف والمهارات والفيديوهات والأسئلة والإجابات والتلميحات وخطوات الشرح.
3. سجّل التعريف في `shared/lesson-engine/registry.ts`. ضع صور الكتاب ونسخة صفحات الدرس داخل `public/lesson-books/<lesson-id>/`.
4. تحقّق من المحتوى والتصحيح والعرض على الهاتف. أضف المعرّف إلى `publishedLessonIds` في `src/features/lesson-engine/publishedLessons.ts` بعد اكتمال المراجعة فقط.
5. ابنِ الواجهة: `npx vite build --configLoader runner`. أعد نسخ `node_modules/pdfjs-dist/build/pdf.worker.min.mjs` إلى `server/public/pdf.worker.min.mjs`.
6. احفظ التغييرات وارفعها إلى GitHub أولًا، ثم انشر الواجهة فقط. لا تستبدل الخادم أو قاعدة البيانات أو ملفات الإعدادات. احتفظ بالأصول القديمة إلى جانب الأصول الجديدة لتجنّب كسر جلسات الزوار المفتوحة.

أسماء الدروس في عناوين التبويبات ديناميكية من تعريف كل درس. الدروس غير المنشورة تبقى في القائمة بأسمائها وتعرض رسالة انتظار المحتوى. رفع ملفات إلى تبويبات CMS القديمة وحده لا ينشر قالب الدرس الجديد.

## حفظ تقدم الاختبار

التصحيح والنتيجة وإعادة الاختبار تعمل محليًا في المتصفح كما في النسخة المعتمدة. لا يُخصم شيء من الدرجة بسبب الإجابات السابقة بعد تصحيح الإجابة. لم تُضَف واجهات الخادم التجريبية، لذلك لم يُغيَّر نظام تقدم الموقع أو حسابات الطلاب.

## الرجوع واستعادة المحتوى القديم

قبل التفعيل توجد نسخة احتياطية مكتملة في Cloudways. يُحفظ أيضًا فهرس الواجهة القديم في مجلد التطبيق الخاص `tmp/lesson-ui-backup-20261004/`.

أداة `script/retire-legacy-lesson-content.py` تعرض خطة فقط افتراضيًا. `--apply` ينقل ملفات محتوى الدروس القديمة إلى مجلد خاص خارج الموقع العام، ويحفظ سجلات CMS ثم يفرغ جداول محتوى الدروس فقط. لا يمس الأسماء أو الهيكل أو SEO أو المستخدمين أو تقدمهم أو كتاب الفصل المرتبط بالمرفقات.

يمكن تشغيل الأداة بـ `--restore` لاستعادة السجلات والملفات دون إعادة قاعدة البيانات كاملة ودون الكتابة فوق محتوى دروس جديد. الأرشيف: `tmp/lesson-content-retired-20261004/`. لا ترفعه إلى GitHub أو أي مكان عام لأنه يتضمن نسخة قاعدة بيانات خاصة.
