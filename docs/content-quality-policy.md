# سياسة اعتماد محتوى شارف

## قاعدة الطبعة الأحدث

لا يدخل أي كتاب إلى مصدر معرفة الدروس لمجرد أن رابطه رسمي أو أن صفحة التحميل تصفه بأنه محدث.

1. يُحدد العام الدراسي والطبعة المطلوبة قبل جلب الملف.
2. يُفتح الملف المرشح في منطقة فحص معزولة.
3. تُقرأ عبارة الطبعة من داخل الغلاف أو صفحة حقوق النشر.
4. يجب أن تتطابق العبارة حرفيًا مع الطبعة المطلوبة، مثل `1448-2026`.
5. عند عدم التطابق يُرفض الملف ويُحذف، ولا يُستخرج منه محتوى درس.
6. عند التطابق تُوثق صفحات الدرس داخل بيانات الدرس قبل السماح بتقرير جودة ناجح.

## مسؤولية الاعتماد

يتولى نظام شارف وفريق التنفيذ التقني الفحص، والتحقق الرياضي، وتجربة رحلة الطالب، وإصلاح الأخطاء قبل عرض نسخة Staging على المؤسس. لا يُطلب من المؤسس تنفيذ فحوص أو إدارة ملفات أو اعتماد تقني يومي.

## بوابة الجودة

لا ينتقل الدرس إلى Production إذا فشل أي شرط حرج، ومنه:

- عدم إثبات الطبعة الأحدث داخل الملف.
- عدم توثيق صفحات الدرس.
- سؤال بلا إجابة صحيحة أو تلميح أو تغذية راجعة.
- ادعاء اعتماد معلم حقيقي دون وجوده.
- معادلة أو نتيجة رياضية غير متحققة.
- فشل تجربة الجوال أو لوحة المفاتيح أو رحلة الطالب الأساسية.
