# تهيئة سيو شارف — 5 أكتوبر 2026

## حدود التنفيذ

تهيئة تقنية لكل المراحل والصفوف والمواد الموجودة في هيكل الموقع. لم تُملأ الدروس الفارغة، ولم تُبدّل المعرّفات الحالية أو التصميم أو نظام الحسابات أو تقدم الطلاب. المحتوى التعليمي المنشور حاليًا: زوايا المضلع، وثماني مقدمات وحدات أول ثانوي رياضيات.

## المنفّذ

- عنوان ووصف عربيان منفصلان لكل صفحة، مع سياق المادة والصف والفصل الدراسي للدرس.
- روابط أساسية Canonical تميّز الصفوف بواسطة grade؛ روابط الدرس الحالية مستقرة. أسماء المرحلة البديلة والشرطات النهائية تُحوّل إلى المسار المعتمد.
- بيانات Open Graph وTwitter ومعلومات JSON-LD للمنصة والصفحة ومسار التصفح والمورد التعليمي عند نشره.
- نص تعليمي فعلي في HTML من أول استجابة، مطابق للنص المرئي، لجميع الزوار وليس نسخة خاصة بالزواحف. زوايا المضلع يتضمن القاعدة ومثال الخماسي ومفهوم الزوايا الخارجية.
- خريطة XML حية لا تضم صفحات الحسابات أو الدروس المنتظرة. لا تواريخ تعديل يومية مصطنعة ولا روابط صفوف مكررة. معلومات الخريطة في لوحة التحكم مصدرها نفس القائمة.
- الخريطة تُحسب آليًا عند كل طلب من المحتوى المنشور وهيكل المادة الحالي؛ لا تنتظر يومًا أو ثلاثة أيام أو أسبوعًا ولا تعتمد على تشغيل جهاز المستخدم. النشر المعتمد يظهر فيها فورًا. قراءة Google اللاحقة ليست جدولًا نتحكم فيه.
- الصفحات الفارغة: 200 مع noindex/follow. الصفحات غير الموجودة والأصول المفقودة: 404. صفحات الحساب والإدارة: noindex/nofollow.
- robots يسمح بزحف الصفحات اللازمة لقراءة noindex ويستبعد API ومجلدات التطبيق. خريطة الموقع مذكورة فيه.
- الروابط الداخلية وفهرس المادة والصف تعمل من عنوان الصفحة ومعرّف الدرس، لا من بيانات زيارة قديمة في المتصفح.
- الإبقاء على البيانات الأولية الصحيحة أثناء بدء الواجهة، وإلغاء طلبات السيو القديمة عند الانتقال السريع.
- محرر السيو يميّز صفحة المادة لكل صف، ولا يحفظ تعديل صف ثانٍ على بيانات الصف الأول.
- تحويل HTTP وwww إلى https://sharfedu.com مع الحفاظ على المسار والاستعلام. شُملت www في شهادة Let's Encrypt القائمة، والتجديد التلقائي مفعّل بالفعل.
- لم تُضف تقييمات أو أسئلة شائعة أو تواريخ فيديو أو بيانات منظمة غير مثبتة بالمحتوى.

## معيار نشر كل درس مستقبلًا

1. مطابقة الاسم والوحدة وترتيب الفصل والصف للكتاب المحدد، وتثبيت معرّفه.
2. إكمال الأقسام الأربعة: صفحات الكتاب، فيديو مناسب ومعلوماته، شرح تفاعلي، اختبار وتصحيح ونتيجة.
3. مراجعة علمية مستقلة للنص والأمثلة والقوانين والإجابات، وتحديد المصدر والإصدار والصفحات دون افتراض حقوق إعادة النشر.
4. توفير شرح نصي مرئي ومراجع للدرس، وليس صور كتاب أو فيديو وحدهما.
5. تسجيل الدرس وموقعه في سجل النشر المشترك، وربط نصه العام في lessonReadingSections. تعميم عنوان الملخص وإحالة الكتاب للدرس الجديد، وعدم ترك عبارة أو صفحات زوايا المضلع في درس آخر.
6. اختبار الهاتف والعرض العربي والتقدم وإعادة الاختبار وإعادة التقدم والنتيجة الدائمة.
7. تشغيل اختبارات السيو والقالب والبناء. نشر النسخة المتطابقة للواجهة والخادم مع نسخ احتياطية، دون استبدال قاعدة البيانات.
8. فحص HTML المباشر: عنوان واحد صحيح، canonical صحيح، وصف خاص، index، بيانات منظمة تطابق المحتوى، ورابط واحد في خريطة الموقع.
9. مراجعة فهرسة الدرس في Search Console بعد النشر. إرسال الخريطة وطلب الفهرسة لا يضمنان القبول أو الترتيب.

الأسماء وحدها لا تنشر درسًا: لا تُدرج الصفحات المنتظرة في خريطة الموقع ولا تحصل على LearningResource حتى المراجعة والنشر الصريحين.

## التحقق والاستعادة

- اختبارات المسارات والسيو، المحافظة على الحسابات والتقدم والتصميم، واختبارات الأقسام الأربعة والقائمة والتهيئة وحدود التنقل بين الفصلين.
- بناء الإنتاج ناجح. فحص TypeScript الشامل يحتوي أخطاء سابقة خارج تعديل السيو في bcrypt وأنواع المستخدم والصور وعارض PDF وImportMeta؛ لم تُعدّل هذه الأنظمة لتجاوزها.
- أربع نسخ خاصة في مجلد tmp خارج جذر الموقع: seo-backup-20261005 وseo-backup-20261005-final وseo-backup-20261005-polish وseo-backup-20261005-grade-editor. تحتوي نسخة الخادم والفهرس والإعدادات ولقطة SQLite متسقة. لم تُستبدل قاعدة الإنتاج.
- أداة publish-production-seo.py تتطلب تطابق بصمة الخادم والحزمة ونجاح فحص معزول على نسخة بيانات قبل التفعيل. --rollback يعيد الخادم والفهرس والإعدادات فقط، لا يرجع بيانات الطلاب إلى تاريخ قديم.
- أصلح تعارض صفحة index.html القديمة مع توجيه Cloudways، ونُقلت الصفحة القديمة إلى نسخة الاستعادة الخاصة، دون حذف دائم. نُقلت أدوات النشر خارج جذر الموقع بعد التفعيل.
- فحص الإنتاج: الروابط الـ19 في الخريطة نجحت بحالة 200 وعنوان ورابط أساسي وبيانات منظمة صحيحة؛ الصفحات المنتظرة والحسابات noindex، المفقودة 404، واجهة معلومات الخريطة الإدارية 401 دون تسجيل دخول. تحويلات HTTP وwww والروابط البديلة نجحت 301 دون تجاوز التحقق من الشهادة.
- مراجعة المتصفح: الهاتف بعرض 390 بكسل بلا تجاوز أفقي؛ تصميم صفحة زوايا المضلع والقائمة محفوظ، والتقدم السابق 100% محفوظ. المعادلات النصية عُزل اتجاهها لتظهر عملية الطرح بالترتيب الصحيح داخل النص العربي.
