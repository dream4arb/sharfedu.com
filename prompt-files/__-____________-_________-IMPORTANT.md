## 🎯 **قواعد viewBox - مهمة جداً (محدثة!):**

### **🔴 المشكلة الشائعة:**
```
❌ نصوص خارج viewBox (جزء يظهر وجزء لا يظهر)
❌ viewBox صغير جداً
❌ نصوص تتجاوز الحدود
```

### **✅ الحل:**

**1. احسب عرض كل نص:**
```
عرض = عدد_الأحرف × (font_size ÷ 1.5)

أمثلة:
font-size=14 → أحرف × 9
font-size=16 → أحرف × 11  
font-size=18 → أحرف × 12
```

**2. احسب viewBox:**
```
viewBox_width = أبعد_نهاية_x + 100
viewBox_height = أبعد_y + 80

مثال:
آخر نص ينتهي في x=523
→ viewBox_width = 523 + 100 = 623
→ استخدم 630 للأمان
```

**3. استخدم text-anchor دائماً:**
```html
<!-- نص وسطي -->
<text x="..." text-anchor="middle">...</text>

<!-- نص يميني -->
<text x="..." text-anchor="end">...</text>

<!-- نص يساري -->
<text x="..." text-anchor="start">...</text>
```

**4. قسّم النصوص الطويلة (> 20 حرف):**
```html
<text x="..." text-anchor="middle">
  <tspan x="..." dy="0">السطر الأول</tspan>
  <tspan x="..." dy="20">السطر الثاني</tspan>
</text>
```

### **5️⃣ 🚨 قاعدة BOM — إلزامية لمنع تشوّه النصوص العربية!**

**المشكلة:** فتح ملف HTML محليًا → المتصفح لا يكتشف UTF-8 → حروف مشوّهة

**الحل الإلزامي:** بعد إنشاء أي ملف HTML، نفّذ:
```python
python3 -c "
with open('FILENAME.html', 'rb') as f:
    content = f.read()
if not content.startswith(b'\xef\xbb\xbf'):
    content = b'\xef\xbb\xbf' + content
    with open('FILENAME.html', 'wb') as f:
        f.write(content)
"
```

**🔴 بدون هذا الأمر = نصوص مشوّهة!**
