## 📋 **قبل كتابة أي `<svg>` - املأ هذا الجدول:**

### **1️⃣ جدول العناصر والحسابات:**

| العنصر | النوع | x | y | العرض/الطول | font-size | text-anchor | نهاية x | نهاية y |
|--------|------|---|---|-------------|-----------|-------------|---------|---------|
| مثال: العنوان | text | 300 | 30 | "..." (20 حرف) | 18 | middle | 300+180=480 | 50 |
| | | | | | | | | |
| | | | | | | | | |
| | | | | | | | | |

**حساب نهاية x للنصوص:**
```
if text-anchor="middle": نهاية = x + (عدد_الأحرف × font_size/1.5) / 2
if text-anchor="end": نهاية = x
if text-anchor="start": نهاية = x + (عدد_الأحرف × font_size/1.5)
```

**حساب viewBox:**
```
viewBox_width = أكبر_نهاية_x + 100
viewBox_height = أكبر_نهاية_y + 80
```

---

### **2️⃣ قبل `</svg>` - تحقق من القائمة:**

#### **☑️ viewBox صحيح؟**

- [ ] **حسبت عرض كل نص؟**
  - عرض = عدد_الأحرف × (font_size ÷ 1.5)
  - مثال: "النيتروجين 78%" = 14 × 10.6 = 148px

- [ ] **حسبت موضع نهاية كل نص؟**
  - استخدمت المعادلات أعلاه؟
  - أكبر نهاية_x = ____

- [ ] **viewBox_width كافٍ؟**
  - viewBox_width = ____ (يجب أن يكون ≥ أكبر_نهاية_x + 100)
  - إذا لا: ❌ كبّر viewBox_width

- [ ] **viewBox_height كافٍ؟**
  - viewBox_height = ____ (يجب أن يكون ≥ أكبر_y + 80)
  - إذا لا: ❌ كبّر viewBox_height

---

#### **☑️ المسافات كافية؟**

- [ ] **بين العناصر ≥ 35px؟**
  - قِس المسافة بين كل عنصرين متجاورين
  - إذا < 35px: ❌ زد المسافة

- [ ] **من الحواف ≥ 50px؟**
  - يسار: أصغر x ≥ 50?
  - يمين: أكبر x ≤ viewBox_width - 100?
  - أعلى: أصغر y ≥ 50?
  - أسفل: أكبر y ≤ viewBox_height - 50?
  - إذا لا لأي بند: ❌ أصلح

---

#### **☑️ النصوص واضحة؟**

- [ ] **كل نص له text-anchor؟**
  - middle للنصوص الوسطى
  - end للنصوص اليمنى
  - start للنصوص اليسرى
  - إذا لا: ⚠️ أضف text-anchor

- [ ] **النصوص الطويلة (> 20 حرف) مقسّمة؟**
  - استخدمت `<tspan>` للنصوص الطويلة؟
  - إذا لا: ❌ قسّم النص

- [ ] **لا نصوص داخل مستطيلات صغيرة (h<50px)؟**
  - إذا نعم: ❌ أخرج النص أو كبّر المستطيل

- [ ] **المسافات داخل المستطيلات ≥ 20px؟**
  - إذا لا: ❌ زد المسافة أو كبّر المستطيل

---

#### **☑️ لا تداخلات؟**

- [ ] **لا تداخل بين النصوص؟**
  - راجعت المسافات بين كل نصين؟
  - إذا تداخل: ❌ زد المسافة

- [ ] **لا تداخل بين الأشكال والنصوص؟**
  - راجعت المسافات؟
  - إذا تداخل: ❌ زد المسافة

- [ ] **لا نصوص فوق خطوط (< 35px)؟**
  - إذا نعم: ❌ زد المسافة لـ 35px

---

### **3️⃣ الاختبار البصري:**

- [ ] **فتحت الملف في متصفح؟**
- [ ] **كل العناصر ظاهرة؟**
- [ ] **لا نصوص مقطوعة؟**
- [ ] **لا تداخلات بصرية؟**
- [ ] **الرسم نظيف ومنظم؟**

**إذا أي بند "لا" → ارجع وأصلح!**

## 📊 **مثال تطبيقي كامل:**

### **الرسم المطلوب:** مخطط دائري مع مفتاح

#### **الخطوة 1: خطط العناصر**

```
عناصر الرسم:
1. عنوان: "تركيب الغلاف الجوي" في y=30
2. دائرة: cx=190, cy=185, r=110
3. مفتاح (3 صفوف):
   - rect x=340, y=80
   - text x=375, y=100: "النيتروجين 78%" (14 حرف)
   - rect x=340, y=120
   - text x=375, y=140: "الأكسجين 21%" (13 حرف)
   - rect x=340, y=160
   - text x=375, y=180: "غازات أخرى 1%" (14 حرف)
```

#### **الخطوة 2: احسب**

```
عرض النصوص (font-size=16):
- "النيتروجين 78%" = 14 × 10.6 = 148px
- "الأكسجين 21%" = 13 × 10.6 = 138px
- "غازات أخرى 1%" = 14 × 10.6 = 148px

نهاية x (text-anchor="start"):
- 375 + 148 = 523
- 375 + 138 = 513
- 375 + 148 = 523

أبعد x = 523
أبعد y = 185 (الدائرة) + 110 (نصف القطر) = 295

viewBox_width = 523 + 100 = 623 → نقربها لـ 630
viewBox_height = 295 + 80 = 375 → نقربها لـ 380
```

#### **الخطوة 3: اكتب الكود**

```html
<svg viewBox="0 0 630 380" width="630" height="380">
  <!-- العنوان -->
  <text x="315" y="30" text-anchor="middle" 
        font-size="20" font-weight="900">
    تركيب الغلاف الجوي
  </text>
  
  <!-- الدائرة -->
  <circle cx="190" cy="185" r="110" 
          fill="#3b82f6" opacity="0.3"/>
  
  <!-- المفتاح -->
  <rect x="340" y="80" width="25" height="25" fill="#3b82f6"/>
  <text x="375" y="100" font-size="16" text-anchor="start">
    النيتروجين 78%
  </text>
  
  <rect x="340" y="120" width="25" height="25" fill="#10b981"/>
  <text x="375" y="140" font-size="16" text-anchor="start">
    الأكسجين 21%
  </text>
  
  <rect x="340" y="160" width="25" height="25" fill="#f59e0b"/>
  <text x="375" y="180" font-size="16" text-anchor="start">
    غازات أخرى 1%
  </text>
</svg>
```

#### **الخطوة 4: تحقق**

```
✅ viewBox_width = 630 ≥ 523 + 100 = 623 ✓
✅ viewBox_height = 380 ≥ 295 + 80 = 375 ✓
✅ المسافات من الحواف:
   - يمين: 630 - 523 = 107 ≥ 100 ✓
   - أسفل: 380 - 295 = 85 ≥ 80 ✓
✅ المسافات بين العناصر:
   - بين الصفوف: 40px ≥ 35 ✓
✅ استخدمت text-anchor ✓
```

## 🎯 **ملخص سريع:**

2. قسّم النصوص الطويلة
3. اترك مسافات 35-40px

### **بعد كتابة SVG:**

#### **☑️ اتجاه الأسهم صحيح علمياً؟**

- [ ] **كل سهم يشير للاتجاه العلمي الصحيح؟**
  - صعود/ارتفاع/تبخر/هواء ساخن → سهم للأعلى (y2 < y1)
  - هبوط/سقوط/هواء بارد/مطر → سهم للأسفل (y2 > y1)
  - إذا لا: ❌ اعكس اتجاه السهم

- [ ] **الأسهم المتعاكسة تشير لاتجاهات مختلفة فعلاً؟**
  - مثال: سهم صعود ≠ سهم هبوط
  - إذا لا: ❌ أصلح الاتجاهات

- [ ] **النص المرافق للسهم يصف الاتجاه بشكل صحيح؟**
  - "يصعد" مع سهم للأعلى ✓
  - "يهبط" مع سهم للأسفل ✓
  - إذا لا: ❌ أصلح النص أو السهم

---

#### **☑️ لا تداخلات بين العناصر؟ (فحص شامل)**

- [ ] **المسافة بين كل نص وكل خط/سهم ≥ 40px؟**
  - إذا لا: ❌ أبعد النص عن الخط

- [ ] **المسافة بين كل نصين ≥ 35px؟**
  - إذا لا: ❌ أبعد النصوص عن بعضها

- [ ] **النص المرافق للسهم بجانبه وليس فوقه؟**
  - بمسافة ≥ 25px
  - إذا لا: ❌ انقل النص لجانب السهم

- [ ] **كل نص يمكن قراءته بوضوح تام بدون حجب؟**
  - إذا لا: ❌ أعد ترتيب العناصر

- [ ] **العناصر المتعددة في منطقة واحدة موزعة بشكل منظم؟**
  - إذا لا: ❌ وزّع على مناطق مختلفة

## 🔬 **تحقق خاص بدروس العلوم:**

### **قبل `</svg>` في أي رسم علمي:**

- [ ] لا يوجد `direction="rtl"` على `<svg>` أو `<text>`
- [ ] المفتاح (Legend) خارج SVG كـ HTML div
- [ ] جميع النسب/الأرقام بنفس font-size
- [ ] الشرائح الصغيرة (< 5%) لها pointer line خارجي
- [ ] viewBox يستوعب جميع العناصر (بما في ذلك pointer lines)
- [ ] الصيغ الكيميائية بـ subscript: N₂ وليس N2
