## 🎯 لماذا هذا الملف؟

دروس العلوم تختلف جذرياً عن دروس الرياضيات أو الإنجليزي أو الدراسات:
- تحتوي على **أنواع رسوم متعددة** (دائرية، طبقات، دورات، مقارنات)
- تحتوي على **مصطلحات عربية + إنجليزية/لاتينية** (N₂, O₂, CO₂)
- تحتوي على **بيانات رقمية** تحتاج جداول ورسوم
- تحتوي على **عمليات ودورات** تحتاج مخططات تدفق
- ملفات PDF غالباً **مسحوبة ضوئياً** (صور وليس نص)

**المرجع:** ملف `الغلاف-الجوي-والطقس.html` — افتحه وادرسه كمثال حي.

## 📋 خطوة 1: التعامل مع PDF العلوم

### المشكلة:
ملفات PDF للعلوم غالباً تكون **مسحوبة ضوئياً** (scanned) — لا يمكن نسخ النص منها.

### الحل:
```python
# 1. حوّل كل صفحة إلى صورة PNG
import pdfplumber
pdf = pdfplumber.open("lesson.pdf")
for i, page in enumerate(pdf.pages):
    img = page.to_image(resolution=200)
    img.save(f"page_{i+1}.png")

# 2. اقرأ كل صورة بالترتيب
# 3. سجّل محتوى كل صفحة في خريطة
```

### خريطة المحتوى (إلزامية):
```
قبل كتابة أي كود، أنشئ هذه الخريطة:

صفحة 1: [العنوان + الأهداف + المقدمة]
صفحة 2: [تركيب الغلاف الجوي + رسم دائري]
صفحة 3: [طبقات الغلاف + رسم الطبقات]
...
صفحة N: [الخلاصة + اختبر نفسك]

ثم تأكد: كل صفحة لها قسم في HTML!
```

## 📋 خطوة 2: أنواع الرسوم في دروس العلوم

### 🥧 النوع 1: المخطط الدائري (Pie Chart)
**الاستخدام:** تركيب/نسب (مثل: غازات الغلاف الجوي، توزيع المياه)

**❌ الأخطاء الشائعة:**
1. وضع المفتاح (Legend) داخل SVG → تداخل مع RTL
2. تصغير خط النسب الصغيرة (1% بخط 9px)
3. استخدام `direction="rtl"` على SVG

**✅ البنية الصحيحة:**
```html
<div style="display:flex; gap:20px; align-items:center; flex-wrap:wrap; justify-content:center;">
  
  <!-- SVG = الدائرة + النسب فقط -->
  <svg viewBox="0 -10 300 310" width="280" height="280">
    <!-- شرائح بـ path مع d="" -->
    <path d="M150,150 L150,30 A120,120 0 1,1 58.2,244...." fill="#4285f4"/>
    
    <!-- النسب الكبيرة داخل الشرائح -->
    <text x="160" y="160" text-anchor="middle" font-size="15" font-weight="700" fill="white">78%</text>
    
    <!-- النسب الصغيرة (< 5%) = pointer line خارج الشريحة -->
    <line x1="115" y1="38" x2="100" y2="12" stroke="#92400e" stroke-width="1.5"/>
    <text x="95" y="9" text-anchor="middle" font-size="15" font-weight="700" fill="#92400e">1%</text>
  </svg>
  
  <!-- HTML = المفتاح -->
  <div style="display:flex; flex-direction:column; gap:12px;">
    <div style="display:flex; align-items:center; gap:10px;">
      <span style="width:20px; height:20px; background:#4285f4; border-radius:4px; flex-shrink:0;"></span>
      <span style="font-size:16px; font-weight:600; color:#334155;">النيتروجين N₂ — 78%</span>
    </div>
    <!-- ... باقي العناصر -->
  </div>
</div>
```

**القواعد الذهبية:**
- جميع النسب بـ **نفس font-size** (14-16px)
- المفتاح = **HTML** (ليس SVG) — لأن SVG لا يتعامل مع العربية + RTL بشكل جيد
- viewBox يبدأ بـ **-10** من الأعلى إذا كان هناك pointer line: `viewBox="0 -10 300 310"`
- حساب مركز كل شريحة: `x = cx + r×0.6×cos(midAngle)`, `y = cy + r×0.6×sin(midAngle)`

### 📊 النوع 2: مخطط الطبقات (Layer Diagram)
**الاستخدام:** طبقات الغلاف الجوي، طبقات الأرض، طبقات التربة

```html
<svg viewBox="0 0 620 480" width="620" height="480">
  <!-- كل طبقة = rect + text -->
  <!-- من الأسفل للأعلى -->
  
  <!-- التروبوسفير (الأقرب للأرض) -->
  <rect x="60" y="380" width="500" height="80" rx="8" fill="#dbeafe" stroke="#3b82f6"/>
  <text x="310" y="425" text-anchor="middle" font-size="16" font-weight="800">التروبوسفير</text>
  <text x="310" y="445" text-anchor="middle" font-size="13" fill="#64748b">0 – 10 كم</text>
  
  <!-- الستراتوسفير -->
  <rect x="60" y="290" width="500" height="80" rx="8" fill="#fef3c7" stroke="#f59e0b"/>
  <!-- ... -->
</svg>
```

**القواعد:**
- الطبقات من **الأسفل للأعلى** (مثل الواقع)
- كل طبقة: **اسم + ارتفاع + ميزة رئيسية**
- ألوان مختلفة لكل طبقة (تدرج حراري: دافئ للقريب، بارد للبعيد)
- مسافة 10px بين الطبقات

---

### 🔄 النوع 3: مخطط الدورة (Cycle Diagram)
**الاستخدام:** دورة الماء، دورة الكربون، دورة النيتروجين

```html
<svg viewBox="0 0 620 400" width="620" height="400">
  <!-- 4 مراحل في مربع دائري -->
  
  <!-- مرحلة 1: أعلى يمين -->
  <rect x="350" y="40" width="200" height="60" rx="12" fill="#dbeafe" stroke="#3b82f6"/>
  <text x="450" y="75" text-anchor="middle" font-size="14" font-weight="700">التبخر</text>
  
  <!-- سهم من 1 إلى 2 -->
  <path d="M450,100 C450,150 170,150 170,100" fill="none" stroke="#3b82f6" stroke-width="2"
        marker-end="url(#arrow)"/>
  
  <!-- مرحلة 2: أعلى يسار -->
  <!-- ... -->
  
  <!-- تعريف السهم -->
  <defs>
    <marker id="arrow" viewBox="0 0 10 10" refX="5" refY="5"
            markerWidth="6" markerHeight="6" orient="auto">
      <path d="M 0 0 L 10 5 L 0 10 z" fill="#3b82f6"/>
    </marker>
  </defs>
</svg>
```

**القواعد:**
- الأسهم تُظهر **اتجاه الدورة** بوضوح
- كل مرحلة في **صندوق ملون** مع اسم واضح
- أضف وصف قصير تحت كل مرحلة
- استخدم `<defs><marker>` للأسهم

### 📈 النوع 4: مخطط المقارنة/العلاقة
**الاستخدام:** العلاقة بين الضغط والحرارة، تصنيف الغيوم بالارتفاع

```html
<svg viewBox="0 0 620 320" width="620" height="320">
  <!-- محور X -->
  <line x1="80" y1="270" x2="580" y2="270" stroke="#334155" stroke-width="2"/>
  <text x="330" y="300" text-anchor="middle" font-size="14">درجة الحرارة</text>
  
  <!-- محور Y -->
  <line x1="80" y1="40" x2="80" y2="270" stroke="#334155" stroke-width="2"/>
  <text x="30" y="155" text-anchor="middle" font-size="14" transform="rotate(-90,30,155)">الارتفاع</text>
  
  <!-- الخط البياني -->
  <polyline points="80,250 200,200 300,230 400,180 500,100" 
            fill="none" stroke="#3b82f6" stroke-width="3"/>
</svg>
```

### 📋 النوع 5: جدول البيانات (HTML Table)
**الاستخدام:** توزيع المياه، مقارنة الطبقات، خصائص الغيوم

```html
<table style="width:100%; border-collapse:collapse; border-radius:16px; overflow:hidden;">
  <thead>
    <tr style="background: linear-gradient(135deg, #1e3a8a, #3b82f6);">
      <th style="padding:14px; color:white; font-size:16px;">المكوّن</th>
      <th style="padding:14px; color:white; font-size:16px;">النسبة %</th>
    </tr>
  </thead>
  <tbody>
    <tr style="background:#f8fafc;">
      <td style="padding:12px; font-weight:600;">المحيطات</td>
      <td style="padding:12px; text-align:center; font-weight:700; color:#2563eb;">97.2</td>
    </tr>
    <!-- ... -->
  </tbody>
</table>
```

**القواعد:**
- `border-radius: 16px` + `overflow: hidden` (زوايا موحدة)
- هيدر الجدول = **نفس لون الهيدر** (الأزرق)
- صفوف متبادلة الألوان (zebra striping)
- الأرقام = **bold + لون مميز**

## 📋 خطوة 3: المحتوى العلمي

### المصطلحات (Vocabulary):
```html
<!-- المصطلح العربي + الإنجليزي/اللاتيني -->
<strong>النيتروجين</strong> N₂
<strong>الأكسجين</strong> O₂
<strong>ثاني أكسيد الكربون</strong> CO₂

<!-- الصيغ الكيميائية: استخدم subscript -->
N₂  (وليس N2)
O₂  (وليس O2)
CO₂ (وليس CO2)
H₂O (وليس H2O)
```

### الوحدات والقياسات:
```html
<!-- استخدم الرموز الصحيحة -->
°س  (درجة مئوية بالعربي)
°C  (درجة مئوية بالإنجليزي)
كم  (كيلومتر)
كم/ساعة  (سرعة)
```

### القوانين والمعادلات:
```html
<div class="rule-box">
  <div class="rule-header">
    <span class="rule-icon">📐</span>
    <h4 class="rule-title">حساب سرعة الرياح</h4>
  </div>
  <div class="rule-formula">
    السرعة (ع) = المسافة (ف) ÷ الزمن (ز)
  </div>
  <div class="rule-explanation">
    تُقاس سرعة الرياح بجهاز يُسمى <strong>الأنيموميتر</strong>.
  </div>
</div>
```

## 📋 خطوة 4: ماذا تشمل وماذا تحذف

### ✅ يجب تضمينه (لا تحذف أبداً):
| النوع | مثال | السبب |
|-------|------|-------|
| كل قسم أكاديمي | الرياح الموسمية | محتوى المنهج |
| المصطلحات | الهباء الجوي، الأيونوسفير | مفردات الدرس |
| القوانين والمعادلات | ع = ف ÷ ز | أساس الاختبار |
| الجداول والبيانات | توزيع المياه 97.2% | حقائق علمية |
| الأمثلة المحلولة | سرعة الرياح = 14÷2 = 7 | تطبيق عملي |
| الرسوم البيانية | المخطط الدائري، الطبقات | فهم بصري |
| المقارنات | الغيوم منخفضة/متوسطة/عالية | تصنيف |

### ❌ يمكن حذفه:
| النوع | مثال | السبب |
|-------|------|-------|
| التجارب المختبرية | "ملاحظة التكثف والتبخر" | تحتاج أدوات حقيقية |
| أقسام "للاطلاع" | معلومات إثرائية جانبية | حشو لا يُختبر |
| أقسام "نشاط" | نشاط جماعي في الصف | لا يمكن تنفيذه رقمياً |

### ⚠️ انتبه - أخطاء شائعة:
```
❌ حذف "الرياح الموسمية" لأنها تبدو ثانوية → هي قسم أكاديمي أساسي!
❌ حذف الجدول الرقمي → البيانات مهمة!
❌ تخطي صفحة كاملة من الـ PDF → كل صفحة تحتوي محتوى!
```

## 📋 خطوة 5: التحقق النهائي (إلزامي!)

### قبل التسليم — 3 أسئلة:

```
السؤال 1: هل أضفت شيئاً من خارج المصدر (PDF)؟
→ إذا نعم: احذفه!

السؤال 2: هل غطيت كامل صفحات المصدر؟
→ افتح كل صفحة وتأكد أن لها قسم في HTML

السؤال 3: هل الأرقام والحقائق صحيحة؟
→ قارن مع المصدر الأصلي
```

### خريطة التحقق:
```
صفحة 1 → القسم: [✅/❌]
صفحة 2 → القسم: [✅/❌]
صفحة 3 → القسم: [✅/❌]
...
صفحة N → القسم: [✅/❌]

كل الصفحات مغطاة؟ → جاهز للتسليم!
```

## 🚨 أخطاء SVG الفادحة في دروس العلوم

### الخطأ 1: `direction="rtl"` في SVG
```html
❌ <svg direction="rtl">  → يدمر كل النصوص العربية!
✅ <svg viewBox="0 0 600 400">  → بدون direction
```
**السبب:** SVG يعكس ترتيب الأحرف عند استخدام direction، مما يشوّه النصوص.

### الخطأ 2: مفتاح الرسم داخل SVG
```html
❌ <svg> <rect fill="blue"/> <text>النيتروجين</text> </svg>
✅ <div style="display:flex;"> <svg>...</svg> <div>المفتاح</div> </div>
```
**السبب:** النصوص العربية في SVG تعاني من مشاكل RTL.

### الخطأ 3: أحجام خطوط مختلفة للنسب
```html
❌ <text font-size="16">78%</text> <text font-size="9">1%</text>
✅ <text font-size="15">78%</text> <text font-size="15">1%</text>
```
**السبب:** تصغير النص لا يحل المشكلة — pointer line هو الحل.

### الخطأ 4: viewBox يقص النص
```html
❌ <svg viewBox="0 0 300 300">  → pointer line عند y=9 لا يظهر!
✅ <svg viewBox="0 -10 300 310">  → viewBox يبدأ من -10
```

## 📊 جدول أنواع الرسوم حسب الموضوع:

| موضوع العلوم | نوع الرسم المطلوب |
|-------------|-------------------|
| تركيب/نسب (غازات، مياه) | مخطط دائري (Pie Chart) |
| طبقات (غلاف جوي، أرض) | مخطط طبقات (Layer Diagram) |
| دورات (ماء، كربون) | مخطط دورة (Cycle Diagram) |
| علاقات (ضغط-حرارة) | رسم بياني (Line Chart) |
| تصنيفات (غيوم، صخور) | مخطط تصنيف (Classification) |
| عمليات (توصيل، حمل) | مخطط تدفق (Flow Diagram) |
| مقارنات (أنواع الهطول) | بطاقات مقارنة (Cards) |
| بيانات رقمية | جدول HTML (Table) |

## 🎯 ملخص سريع:

```
1. حوّل PDF لصور → اقرأ كل صفحة → أنشئ خريطة المحتوى
2. لكل نوع بيانات → اختر نوع الرسم المناسب من الجدول أعلاه
3. SVG: بدون direction="rtl" + مفاتيح HTML + خطوط موحدة
4. المحتوى: لا تحذف أقسام أكاديمية + لا تضف من خارج المصدر
5. التحقق: كل صفحة PDF لها قسم HTML + الأرقام صحيحة
```

## 🧪 أنواع دروس العلوم الأخرى:

### **الفيزياء:**
| المحتوى | نوع الرسم |
|---------|-----------|
| القوى والحركة | أسهم متجهة (vectors) على SVG |
| الدوائر الكهربائية | مخطط دائرة (خطوط + رموز) |
| الموجات | خط متموج (sin wave) |
| القوانين (ع = ف ÷ ز) | rule-box مع rule-formula |
| المقارنات (موصل/عازل) | بطاقات مقارنة أو جدول |

### **الكيمياء:**
| المحتوى | نوع الرسم |
|---------|-----------|
| الجدول الدوري (جزء منه) | جدول HTML ملون |
| التفاعلات | مخطط تدفق بأسهم |
| تركيب الذرة | SVG دوائر متداخلة |
| النسب والتركيز | مخطط دائري أو أعمدة |
| الصيغ (H₂O, NaCl) | subscript دائماً: ₂ وليس 2 |

### **الأحياء:**
| المحتوى | نوع الرسم |
|---------|-----------|
| الخلية وأجزاؤها | SVG مع تسميات خارجية |
| أجهزة الجسم | مخطط تدفق (دورة دموية مثلاً) |
| التصنيف | مخطط شجري (tree diagram) |
| العمليات (التنفس/البناء الضوئي) | مخطط دورة بأسهم |
| المقارنات (خلية نباتية/حيوانية) | جدول مقارنة أو بطاقات |

### **القاعدة العامة:**
```
بيانات رقمية → جدول HTML أو مخطط دائري/أعمدة
عملية/دورة → مخطط تدفق بأسهم
طبقات/مستويات → مخطط طبقات
تصنيف → مخطط شجري أو بطاقات
مقارنة → جدول مقارنة
قانون/معادلة → rule-box مع formula
```
