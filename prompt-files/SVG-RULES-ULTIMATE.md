# 🎯 **القواعد النهائية لرسوم SVG - نجاح 100%**

---

## 🚨 **القواعد الـ 7 الذهبية - اتبعها بالحرف!**

---

### **📐 القاعدة 1: حساب viewBox الصحيح (مهم جداً!)**

#### **❌ الخطأ الشائع:**
```html
<!-- viewBox صغير جداً -->
<svg viewBox="0 0 500 300" width="500" height="300">
  <text x="480" y="50">نص طويل جداً هنا</text>  ← يتجاوز 500!
</svg>
```

#### **✅ الصحيح:**
```
viewBox = (العنصر الأبعد x + عرضه) + هامش 80px
viewBox = (العنصر الأبعد y + ارتفاعه) + هامش 80px
```

#### **📝 طريقة الحساب:**

**الخطوة 1: حدد أبعد عنصر**
```javascript
// مثال: رسم يحتوي على:
// - مستطيل عند x=50, width=400 → أبعد نقطة = 450
// - نص عند x=480, عرض النص ~100px → أبعد نقطة = 580
// - دائرة عند cy=250, ry=50 → أبعد نقطة = 300

أبعد x = 580
أبعد y = 300
```

**الخطوة 2: أضف هامش أمان**
```javascript
viewBox_width = 580 + 80 = 660
viewBox_height = 300 + 80 = 380
```

**الخطوة 3: اكتب viewBox**
```html
<svg viewBox="0 0 660 380" width="660" height="380">
```

---

### **🔢 القاعدة 2: حساب عرض النص (مهم جداً!)**

#### **قاعدة التقدير السريع:**

```javascript
عرض النص التقريبي = عدد الأحرف × 8 (إذا font-size=14)
عرض النص التقريبي = عدد الأحرف × 10 (إذا font-size=16)
عرض النص التقريبي = عدد الأحرف × 12 (إذا font-size=18)
```

#### **مثال:**

```html
<!-- نص = "الغلاف الجوي" = 12 حرف -->
<!-- font-size=16 -->
<!-- العرض المتوقع = 12 × 10 = 120px -->

<text x="400" y="50" font-size="16">الغلاف الجوي</text>
<!-- النص يمتد من 400 إلى 520 تقريباً -->
<!-- لذا viewBox يجب أن يكون > 520 + 80 = 600 -->
```

---

### **📏 القاعدة 3: الهوامش الإلزامية**

#### **هوامش داخل viewBox:**

```
من اليسار: 50px (minimum)
من اليمين: 80px (minimum) - لأن النصوص العربية تمتد لليسار
من الأعلى: 50px (minimum)
من الأسفل: 50px (minimum)
```

#### **مثال عملي:**

```html
<svg viewBox="0 0 600 400" width="600" height="400">
  <!-- العنوان -->
  <text x="300" y="30">العنوان</text>  ← 30 من الأعلى ✓
  
  <!-- محتوى -->
  <rect x="80" y="80" width="440" height="280"/>  
  <!-- 80 من اليسار ✓ -->
  <!-- 80+440=520, 600-520=80 من اليمين ✓ -->
  <!-- 80 من الأعلى ✓ -->
  <!-- 80+280=360, 400-360=40 من الأسفل ⚠️ قليل! -->
</svg>
```

---

### **📝 القاعدة 4: تقسيم النصوص الطويلة**

#### **❌ خطأ شائع جداً:**

```html
<text x="200" y="100">نص طويل جداً لا يتسع في سطر واحد</text>
<!-- سيتجاوز حدود viewBox! -->
```

#### **✅ الحل: استخدم tspan**

```html
<text x="200" y="100" text-anchor="middle" font-size="14">
  <tspan x="200" dy="0">نص طويل جداً</tspan>
  <tspan x="200" dy="18">يتسع في سطرين</tspan>
</text>
```

#### **قاعدة:**
```
إذا كان النص > 20 حرف:
  → قسمه لسطرين أو أكثر
  
إذا كان font-size=14:
  → المسافة بين الأسطر (dy) = 18-20
  
إذا كان font-size=16:
  → المسافة بين الأسطر (dy) = 20-24
```

---

### **🎨 القاعدة 5: text-anchor للنصوص**

#### **استخدم text-anchor لمنع تجاوز الحدود:**

```html
<!-- ✅ للنصوص في المنتصف -->
<text x="300" y="50" text-anchor="middle">نص في المنتصف</text>

<!-- ✅ للنصوص على اليمين -->
<text x="550" y="50" text-anchor="end">نص على اليمين</text>

<!-- ✅ للنصوص على اليسار -->
<text x="50" y="50" text-anchor="start">نص على اليسار</text>
```

#### **فائدة:**
```
text-anchor="middle" → النص يتوسط الإحداثي x
text-anchor="end" → النص ينتهي عند x (لا يتجاوزه)
text-anchor="start" → النص يبدأ من x
```

### **📊 القاعدة 6: قائمة التحقق قبل إغلاق SVG**

#### **✅ قبل كتابة `</svg>` تحقق من:**

```javascript
// 1. هل viewBox كافٍ؟
viewBox_width >= (أبعد x + عرض العنصر + 80)
viewBox_height >= (أبعد y + ارتفاع العنصر + 80)

// 2. هل جميع النصوص داخل الحدود؟
for كل نص:
  if (نص.x + عرض_النص > viewBox_width - 80):
    ❌ مشكلة! قلل النص أو كبر viewBox
    
// 3. هل المسافات كافية؟
for كل عنصرين متجاورين:
  if (المسافة_بينهما < 35px):
    ❌ مشكلة! زد المسافة

// 4. هل العناصر مرئية؟
for كل عنصر:
  if (x < 50 || y < 50):
    ❌ قريب جداً من الحافة!
  if (x > viewBox_width - 100):
    ❌ قريب جداً من الحافة اليمنى!
```

---

### **🔍 القاعدة 7: اختبار بصري**

#### **بعد كتابة SVG:**

```
1. هل ترى جميع العناصر؟
   → إذا لا: كبر viewBox

2. هل جميع النصوص مقروءة؟
   → إذا لا: قسمها لأسطر

3. هل هناك تداخل؟
   → إذا نعم: زد المسافات

4. هل الرسم متوازن؟
   → إذا لا: أعد ترتيب العناصر
```

### **مثال 1: رسم المخطط الدائري**

```html

  <!-- المفتاح على اليمين -->
  <rect x="340" y="80" width="25" height="25"/>

  <!-- النص يمتد ~120px من 375 = 495 -->
  <!-- 495 قريب جداً من 500! -->

```

#### **✅ الصحيح:**
```html
<svg viewBox="0 0 580 320" width="580" height="320">
  <!-- زدنا viewBox من 500 إلى 580 -->
  <rect x="340" y="80" width="25" height="25"/>
  <text x="375" y="100">النيتروجين 78%</text>
  <!-- الآن 495 < 580 - 80 = 500 ✓ -->
</svg>
```

## 🎯 **Template جاهز للاستخدام:**

### **نموذج رسم آمن 100%:**

```html
<svg viewBox="0 0 [WIDTH] [HEIGHT]" width="[WIDTH]" height="[HEIGHT]">
  <!-- حساب WIDTH و HEIGHT:
    1. حدد أبعد عنصر x + عرضه
    2. أضف 80px
    3. هذا هو WIDTH
    
    1. حدد أبعد عنصر y + ارتفاعه
    2. أضف 80px
    3. هذا هو HEIGHT
  -->
  
  <!-- العنوان (دائماً في الأعلى) -->
  <text x="[WIDTH/2]" y="30" text-anchor="middle" font-size="18" font-weight="900">
    العنوان هنا
  </text>
  
  <!-- المحتوى (ابدأ من y=60 على الأقل) -->
  <!-- ... -->
  
  <!-- تأكد: 
    - جميع x > 50
    - جميع x < WIDTH - 100
    - جميع y > 50
    - جميع y < HEIGHT - 50
  -->
</svg>
```

## ✅ **قائمة التحقق النهائية:**

### **قبل إرسال أي رسم:**

- [ ] **viewBox محسوب صحيح؟**
  - [ ] WIDTH >= (أبعد x + 100)
  - [ ] HEIGHT >= (أبعد y + 80)

- [ ] **جميع النصوص داخل الحدود؟**
  - [ ] لا يوجد نص يتجاوز WIDTH - 80
  - [ ] النصوص الطويلة مقسمة

- [ ] **المسافات كافية؟**
  - [ ] بين العناصر: ≥ 35px
  - [ ] من الحواف: ≥ 50px

- [ ] **استخدمت text-anchor؟**
  - [ ] middle للنصوص الوسطى
  - [ ] end للنصوص اليمنى
  - [ ] start للنصوص اليسرى

- [ ] **لا تداخلات؟**
  - [ ] راجعت المسافات
  - [ ] لا تقاطعات بين العناصر

**إذا كلها ✓ → الرسم جاهز! 🎉**

## 🚨 **القاعدة 8: ممنوع `direction="rtl"` في SVG**

**سبب المشكلة:** SVG يفسر `direction="rtl"` بشكل مختلف عن HTML — يعكس ترتيب الأحرف العربية بدلاً من اتجاه الكتابة.

**النتيجة:** تداخل النصوص + تشوه الحروف + مسافات خاطئة.

```html
❌ <svg direction="rtl" viewBox="0 0 600 400">
❌ <text direction="rtl">نص عربي</text>

✅ <svg viewBox="0 0 600 400">
✅ <text text-anchor="middle" font-family="Tajawal, sans-serif">نص عربي</text>
```

**تذكر:** `dir="rtl"` على `<html>` = صحيح. `direction="rtl"` على `<svg>` أو `<text>` = ممنوع.

## 🚨 **القاعدة 9: مفاتيح الرسوم (Legends) = HTML**

**المشكلة:** النصوص العربية في مفاتيح SVG تعاني من مشاكل محاذاة بسبب RTL.

**الحل:** فصل SVG (الرسم) عن HTML (المفتاح) باستخدام flexbox:

```html
<div style="display:flex; gap:20px; align-items:center; flex-wrap:wrap; justify-content:center;">
  <svg><!-- الرسم البياني فقط --></svg>
  <div style="display:flex; flex-direction:column; gap:12px;">
    <div style="display:flex; align-items:center; gap:10px;">
      <span style="width:20px;height:20px;background:#4285f4;border-radius:4px;flex-shrink:0;"></span>
      <span style="font-size:16px;font-weight:600;">النيتروجين N₂ — 78%</span>
    </div>
  </div>
</div>
```

**ينطبق على:** المخططات الدائرية، الأعمدة، أي رسم يحتاج مفتاح ألوان.

## 🚨 **القاعدة 10: أحجام خطوط موحدة**

**المشكلة:** تصغير حجم خط النسب الصغيرة (مثل 1% بحجم 9px بينما 78% بحجم 16px).

**القاعدة:** كل الأرقام/النسب في الرسم الواحد = **نفس font-size**.

**الحل للشرائح الصغيرة:** pointer line خارج الشريحة + نص بالحجم الكامل:

```html
<line x1="115" y1="38" x2="100" y2="12" stroke="#92400e" stroke-width="1.5"/>
<text x="95" y="9" text-anchor="middle" font-size="15" font-weight="700" fill="#92400e">1%</text>
```

**ملاحظة:** إذا خرج النص من viewBox ← وسّع viewBox: `viewBox="0 -10 300 310"`
