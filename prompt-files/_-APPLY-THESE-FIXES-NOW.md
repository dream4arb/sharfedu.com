## ✅ **الإصلاح 1: رسم تجربة جاليليو** (سطر ~190)

### **ابحث عن:**
```html
<svg viewBox="0 0 620 260" width="620" height="260">
```

### **استبدل بـ:**
```html
<svg viewBox="0 0 640 300" width="640" height="300">
```

### **ثم ابحث عن:**
```html
<text x="310" y="250" text-anchor="middle" font-size="15" font-weight="700" fill="#dc2626">النتيجة: كتلة الدورق المحقون أكبر ← الهواء له كتلة!</text>
```

### **استبدل بـ:**
```html
<text x="310" y="265" text-anchor="middle" font-size="14" font-weight="700" fill="#dc2626">
  <tspan x="310" dy="0">النتيجة: كتلة الدورق المحقون أكبر</tspan>
  <tspan x="310" dy="18">← إذن الهواء له كتلة!</tspan>
</text>
```
