## 📐 **خطوة إضافية: حساب viewBox (إلزامية!):**

### **قبل كتابة أي `<svg>` - احسب viewBox:**

**الخطوة 1: اجمع بيانات جميع العناصر**

```
عنصر 1: نص "..." في x=..., y=...
  - عدد الأحرف: __
  - font-size: __
  - text-anchor: __
  - عرض تقريبي: عدد × (font-size ÷ 1.5) = __
  - نهاية x: __ (حسب text-anchor)

عنصر 2: مستطيل في x=..., y=..., width=..., height=...
  - نهاية x: x + width = __
  - نهاية y: y + height = __

عنصر 3: ...
```

**الخطوة 2: حدد أبعد نقطة**

```
أبعد x من جميع العناصر: __
أبعد y من جميع العناصر: __
```

**الخطوة 3: احسب viewBox**

```
viewBox_width = أبعد_x + 100
viewBox_height = أبعد_y + 80
```

**الخطوة 4: اكتب SVG**

```html
<svg viewBox="0 0 [viewBox_width] [viewBox_height]" 
     width="[viewBox_width]" 
     height="[viewBox_height]">
  <!-- ... -->
</svg>
```

---

### **📋 مثال عملي:**

```
الرسم المطلوب: مخطط مع 3 نصوص

البيانات:
1. عنوان: "تركيب الغلاف الجوي" (19 حرف, font-size=18, text-anchor=middle, x=300)
   - عرض = 19 × 12 = 228px
   - نصف_عرض = 114px
   - نهاية_x = 300 + 114 = 414

2. نص: "النيتروجين 78%" (14 حرف, font-size=16, text-anchor=start, x=375)
   - عرض = 14 × 10.6 = 148px
   - نهاية_x = 375 + 148 = 523

3. نص: "الأكسجين 21%" (13 حرف, font-size=16, text-anchor=start, x=375)
   - عرض = 13 × 10.6 = 138px
   - نهاية_x = 375 + 138 = 513

أبعد_x = 523
أبعد_y = 200 (تقريباً)

viewBox_width = 523 + 100 = 623 → نقربها لـ 630
viewBox_height = 200 + 80 = 280 → نقربها لـ 300

الكود النهائي:
<svg viewBox="0 0 630 300" width="630" height="300">
  <!-- ... -->
</svg>
```

## 🔬 **Workflow خاص بدروس العلوم:**

### **الخطوة 0: اكتشف نوع الدرس**
```
هل الدرس يحتوي على:
- رسوم بيانية أو نسب مئوية؟ → مخططات دائرية/أعمدة
- طبقات أو مستويات؟ → مخطط طبقات
- دورات أو عمليات؟ → مخطط دورة بأسهم
- بيانات رقمية؟ → جداول HTML
- مصطلحات علمية؟ → N₂, O₂, CO₂ بـ subscript
```

### **الخطوة 1: خريطة المحتوى (قبل كتابة أي كود!)**
```
افتح كل صفحة من PDF وسجّل:
صفحة 1 → [المحتوى] → قسم HTML: [الاسم]
صفحة 2 → [المحتوى] → قسم HTML: [الاسم]
...
```

### **الخطوة 2: SVG بدون أخطاء RTL**
```
❌ direction="rtl" في SVG
❌ مفتاح داخل SVG
❌ أحجام خطوط مختلفة
✅ text-anchor="middle"
✅ مفاتيح HTML
✅ pointer line للشرائح الصغيرة
```

### **الخطوة 3: التحقق النهائي**
```
□ كل صفحة PDF مغطاة في HTML
□ لا محتوى من خارج المصدر
□ لا أقسام أكاديمية محذوفة
□ الأرقام والنسب صحيحة
```

## 🚨 خطوة إلزامية أخيرة: إضافة BOM

**بعد الانتهاء من إنشاء أي ملف HTML وقبل التسليم:**

```python
python3 -c "
with open('FILENAME.html', 'rb') as f:
    content = f.read()
if not content.startswith(b'\xef\xbb\xbf'):
    content = b'\xef\xbb\xbf' + content
    with open('FILENAME.html', 'wb') as f:
        f.write(content)
"
```

**بدون هذا = النصوص العربية تظهر مشوّهة في المتصفح!**
