# 📏 ورقة الغش - المسافات في الرسوم SVG

## 🚨 **اطبع هذه الورقة واحتفظ بها أمامك!**

---

## 🔢 **المعادلات الأساسية:**

### **1. عرض النص:**
```javascript
عرض_النص = عدد_الأحرف × (font_size ÷ 1.5)

أمثلة:
font-size=14 → أحرف × 9.3
font-size=16 → أحرف × 10.6
font-size=18 → أحرف × 12
```

### **2. نهاية النص:**
```javascript
if text-anchor="middle":
  نهاية_x = x + (عرض_النص ÷ 2)

if text-anchor="end":
  نهاية_x = x

if text-anchor="start":
  نهاية_x = x + عرض_النص
```

### **3. viewBox:**
```javascript
viewBox_width = أبعد_نهاية_x + 100
viewBox_height = أبعد_y + 80
```

## 📊 **الجدول السريع:**

| الموقف | الحد الأدنى | الموصى به |
|--------|-------------|-----------|
| **نص ← خط عمودي/أفقي** | 30px | 35-40px |
| **نص ← سهم** | 30px | 35-40px |
| **نص داخل مستطيل صغير (h<50)** | ❌ ممنوع | ضعه خارجاً |
| **نص داخل مستطيل كبير (h>80)** | 20px من الحواف | 25-30px |
| **نص ← دائرة/بيضاوي صغير** | ❌ ممنوع | 25-35px خارجه |
| **نص ← دائرة كبيرة (r>50)** | 25px من الحافة | 30-35px |
| **بين سطرين** | 20px | 25-30px |
| **بين شكلين** | 15px | 20-25px |
| **هامش من viewBox (يمين)** | 80px | 100px |
| **هامش من viewBox (يسار/أعلى/أسفل)** | 50px | 80px |

## 📐 **أمثلة حساب:**

### **مثال 1: نص بسيط**
```
النص: "النيتروجين 78%"
عدد الأحرف: 14
font-size: 16
text-anchor: "start"
x: 375

الحساب:
عرض = 14 × 10.6 = 148px
نهاية_x = 375 + 148 = 523

viewBox_width يجب أن يكون ≥ 523 + 100 = 623
→ استخدم 630 للأمان
```

### **مثال 2: نص في المنتصف**
```
النص: "تركيب الغلاف الجوي"
عدد الأحرف: 19
font-size: 18
text-anchor: "middle"
x: 300

الحساب:
عرض = 19 × 12 = 228px
نصف_العرض = 228 ÷ 2 = 114px
يسار = 300 - 114 = 186
يمين = 300 + 114 = 414

تأكد:
186 ≥ 50? ✓
414 ≤ viewBox_width - 100? تحقق!
```

## ✅ **قائمة التحقق السريعة:**

**قبل `</svg>` تحقق:**

- [ ] حسبت عرض كل نص؟
- [ ] حسبت نهاية كل نص؟
- [ ] viewBox ≥ أبعد_نهاية + 100؟
- [ ] استخدمت text-anchor؟
- [ ] لا نصوص في مستطيلات صغيرة؟
- [ ] المسافات ≥ 35px؟
- [ ] النصوص الطويلة مقسمة؟
- [ ] الهوامش كافية؟

**إذا كلها ✓ → الرسم جيد!**

---

## 🚨 **تنبيهات سريعة:**

```
❌ لا تخمن viewBox عشوائياً
✅ احسبه بالمعادلات

❌ لا تنسى text-anchor
✅ استخدمه لكل نص

❌ لا تضع نصوص في مستطيلات صغيرة
✅ أخرجها أو كبّر المستطيل

❌ لا تضع نصوص قرب الحدود (< 100px)
✅ اترك هامش 100px من اليمين

❌ لا تكتب نصوص طويلة في سطر واحد
✅ قسمها باستخدام <tspan>
```

## 🔬 **ملاحظات خاصة بدروس العلوم:**

```
Pie Chart:
  - المفتاح = HTML flexbox (ليس SVG)
  - جميع النسب = نفس font-size
  - شريحة < 5% = pointer line خارجها
  - viewBox يبدأ من -10 إذا pointer فوق: "0 -10 300 310"

SVG عام:
  - ❌ direction="rtl" = ممنوع
  - ✅ text-anchor="middle" = آمن

الصيغ الكيميائية:
  - N₂ (وليس N2)
  - O₂, CO₂, H₂O
```
