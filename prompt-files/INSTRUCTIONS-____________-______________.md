## 📋 القواعد الأساسية

### 1️⃣ **المحتوى:**
- ✅ اشرح الدرس **فقط من الملف المرفق** - لا تضيف معلومات خارجية
- ✅ اجعل الشرح **شاملاً وواضحاً جداً** - بحيث يكون هذا الملف هو **المرجع الأول** للطالب
- ✅ **لا تجعل الطالب يحتاج لأي مصدر آخر** - كل ما يحتاجه موجود في الملف
- ✅ نظم المحتوى في **صناديق وإطارات واضحة**
- ✅ استخدم **أمثلة محلولة** وإبرازات ملونة للنقاط المهمة

### ⚠️ **1.5️⃣ الرسوم التوضيحية (مهم جداً!):**

**🔴 للدروس الهندسية/الرياضيات/العلوم:**
- ✅ **يجب** إضافة رسوم SVG توضيحية
- ✅ **لا يمكن** إنشاء درس هندسة بدون رسوم!
- ✅ راجع ملف `SVG-DIAGRAMS-GUIDE.md` للتفاصيل
- ✅ انظر إلى `zawaya-almudallae.html` كمثال (18 رسم SVG)

**🚫 تحذير - لا أيقونات بدلاً من الرسوم!**
- ❌ **لا تستخدم** أيقونات emoji (📏 📐 ✂️ 🔄) في بطاقات الخصائص!
- ❌ **لا تستخدم** أيقونات بدلاً من الرسوم التوضيحية!
- ✅ استخدم رسوم SVG فعلية لكل خاصية/مفهوم

**🎨 قاعدة مهمة - لا تداخل في الرسومات!**
- ❌ **لا تضع** النصوص فوق الخطوط مباشرة
- ❌ **لا تضع** الأرقام داخل الأشكال الصغيرة
- ❌ **لا تجعل** التسميات تتداخل مع العناصر
- ✅ **اترك مسافة** 30-40px بين النصوص والخطوط
- ✅ **ضع التسميات** خارج الأشكال (أو داخلها إذا كانت كبيرة كفاية)
- ✅ **اجعل الرسم** نظيفاً ومنظماً

**مثال - خط زمني:**
```
❌ خطأ: <text y="100">التاريخ</text> مع <line y="100"/>
✅ صح: <text y="60">التاريخ</text> مع <line y="100"/> (مسافة 40px)
```

**الأيقونات مسموحة فقط في:**
- ✅ العناوين الرئيسية (📖 مقدمة الدرس)
- ✅ عناوين الأقسام (📝 أمثلة محلولة)
- ✅ زر الفوتر

**الأيقونات ممنوعة في:**
- ❌ بطاقات الخصائص (property-card)
- ❌ توضيح القوانين والنظريات
- ❌ شرح المفاهيم
- ❌ الأمثلة المحلولة

**📊 الحد الأدنى للرسوم:**
- درس بسيط: **8-12 رسم SVG**
- درس متوسط: **12-18 رسم SVG**
- درس معقد: **15-25 رسم SVG**

**قاعدة:** لكل screen تمرير يجب رسم SVG واحد على الأقل!

**📊 متى تضيف رسوم SVG؟**
- 📐 الرياضيات: أشكال هندسية، مضلعات، زوايا، رسوم بيانية
- 🔬 العلوم: تجارب، أجهزة، دورات، تراكيب
- 🌍 الجغرافيا: خرائط، تضاريس
- 🧬 الأحياء: أعضاء، خلايا، أنظمة

**❌ متى لا تحتاج رسوم؟**
- 📖 اللغات: قواعد نحوية، مفردات (إلا إذا كانت رسوم توضيحية بسيطة)
- 📜 التاريخ: أحداث، شخصيات (إلا الخرائط والخطوط الزمنية)

### 2️⃣ **التنسيق الموحد (إلزامي):**
هذه الأقسام **يجب أن تكون موحدة** في كل درس:

#### أ) **الهيدر (Hero Section):**

**🔴 مهم جداً - لون الهيدر موحد (هوية الموقع):**
```css
/* ✅ اللون الموحد الإلزامي */
background: linear-gradient(135deg, #1e3a8a 0%, #2563eb 50%, #3b82f6 100%);
```

**❌ لا تغيّر لون الهيدر أبداً!**
- لا برتقالي، لا أحمر، لا أخضر
- الهيدر دائماً **أزرق** في جميع الدروس
- هذا جزء من **هوية منصة شارف**

```html
<section class="hero">
  <div class="hero-deco">
    <div class="ds"></div>
    <div class="ds"></div>
    <div class="ds"></div>
  </div>
  
  <div class="hero-card">
    <h1>📚 [عنوان الدرس]</h1>
    <p class="hsub">[عنوان فرعي] - [اسم المادة]</p>
    <div class="hero-badge">📚 منصة شارف التعليمية</div>
  </div>
</section>
```

#### ب) **الفوتر (Footer):**
```html
<footer>
  <p style="margin-bottom: 8px;">تم تطوير هذا المحتوى التعليمي بالذكاء الاصطناعي ليكون مساعداً تفاعلياً ولا يُغني عن الكتاب المدرسي</p>
  <p><strong>منصة شارف التعليمية</strong> 📚</p>
</footer>
```

#### ج) **التمارين (نظام سؤال واحد + زر التالي):**
- ✅ كل سؤال في `<div data-exercise="N">`
- ✅ السؤال الأول فقط يظهر، الباقي `display: none`
- ✅ بعد الإجابة يظهر زر "السؤال التالي ⬅️"
- ✅ في النهاية: صفحة النتائج مع النسبة المئوية

### 3️⃣ **التنسيق المرن (حسب المحتوى):**
باقي التنسيق **مرن** ويعتمد على نوع المحتوى:

#### للرياضيات:
- استخدم صناديق ملونة للقوانين والمعادلات
- رسوم توضيحية إذا لزم الأمر
- أمثلة محلولة خطوة بخطوة

#### للغات:
- جداول للمفردات
- صناديق للقواعد النحوية
- أمثلة محلولة مع إبرازات ملونة

#### للعلوم:
- رسوم توضيحية للمفاهيم
- جداول للمقارنات
- تجارب أو ملاحظات في صناديق

#### للدراسات الاجتماعية:
- خرائط زمنية
- جداول للأحداث والتواريخ
- صناديق للشخصيات المهمة

## 📝 **قاعدة مهمة جداً - شرح الإجابات في التمارين:**

### **🔴 مشكلة شائعة:**

في قسم التمارين والاختبارات، يتم وضع:
```javascript
// ❌ خطأ شائع - لا توضيح!
expDiv.textContent = '✅ إجابة صحيحة! أحسنت!';
expDiv.textContent = '❌ إجابة خاطئة';
```

**المشكلة:**
- الطالب لا يعرف **لماذا** الإجابة صحيحة
- الطالب لا يتعلم من الخطأ
- لا توجد قيمة تعليمية

---

### **✅ الحل الصحيح:**

**يجب شرح كل إجابة بالتفصيل!**

#### **مثال 1: سؤال رياضيات**

**❌ خطأ:**
```javascript
if (isCorrect) {
  expDiv.textContent = '✅ إجابة صحيحة!';
} else {
  expDiv.textContent = '❌ إجابة خاطئة';
}
```

**✅ صح:**
```javascript
if (isCorrect) {
  expDiv.textContent = '✅ إجابة صحيحة! مجموع الزوايا الداخلية للخماسي = (5-2) × 180° = 3 × 180° = 540°';
} else {
  expDiv.textContent = '❌ إجابة خاطئة. مجموع الزوايا الداخلية للخماسي = (5-2) × 180° = 3 × 180° = 540° وليس 360°';
}
```

---

#### **مثال 2: سؤال تاريخي**

**❌ خطأ:**
```javascript
expDiv.textContent = '✅ صحيح!';
```

**✅ صح:**
```javascript
expDiv.textContent = '✅ صحيح! أبو بكر الصديق هو أول الخلفاء الراشدين، وبُويع بالخلافة عام 11هـ بعد وفاة النبي ﷺ';
```

---

#### **مثال 3: سؤال علوم**

**❌ خطأ:**
```javascript
expDiv.textContent = '❌ خطأ - الإجابة الصحيحة مظللة باللون الأخضر';
```

**✅ صح:**
```javascript
expDiv.textContent = '❌ خطأ. التمثيل الضوئي يحدث في النهار وليس الليل، لأنه يحتاج إلى ضوء الشمس لتحويل الطاقة الضوئية إلى طاقة كيميائية';
```

---

### **📋 القاعدة الذهبية:**

**كل سؤال يجب أن يحتوي على:**

1. ✅ **للإجابة الصحيحة:**
   - علامة ✅
   - تأكيد الإجابة
   - **شرح السبب** أو **المعلومة الأساسية**

2. ❌ **للإجابة الخاطئة:**
   - علامة ❌
   - **الإجابة الصحيحة**
   - **شرح السبب** أو **توضيح الخطأ**

---

### **💡 أمثلة عملية حسب نوع السؤال:**

#### **نوع 1: حقيقة/معلومة**
```javascript
// السؤال: من أول الخلفاء الراشدين؟
// الإجابة الصحيحة: أبو بكر الصديق

expDiv.textContent = '✅ صحيح! أبو بكر الصديق رضي الله عنه هو أول الخلفاء الراشدين، بُويع بالخلافة عام 11هـ في سقيفة بني ساعدة بعد وفاة النبي ﷺ';
```

#### **نوع 2: حساب/قانون**
```javascript
// السؤال: ما مجموع الزوايا الداخلية للسداسي؟
// الإجابة الصحيحة: 720°

expDiv.textContent = '✅ صحيح! مجموع الزوايا الداخلية للسداسي = (n-2) × 180° = (6-2) × 180° = 4 × 180° = 720°';
```

#### **نوع 3: تعريف/مفهوم**
```javascript
// السؤال: المستطيل له كم زاوية قائمة؟
// الإجابة الصحيحة: 4 زوايا

expDiv.textContent = '✅ صحيح! المستطيل له 4 زوايا قائمة (كل زاوية = 90°)، وهذه من الخصائص الأساسية التي تميز المستطيل عن متوازي الأضلاع العادي';
```

#### **نوع 4: مقارنة**
```javascript
// السؤال: من الذي لُقب بالفاروق؟
// الإجابة الخاطئة: أبو بكر
// الإجابة الصحيحة: عمر بن الخطاب

expDiv.textContent = '❌ خطأ. الفاروق هو لقب عمر بن الخطاب رضي الله عنه، لقبه به النبي ﷺ لأنه فَرَّق بين الحق والباطل';
```

---

### **🎯 قائمة التحقق:**

قبل إرسال أي درس، تأكد من:

- [ ] كل سؤال له شرح مفصل للإجابة الصحيحة
- [ ] كل سؤال له توضيح للخطأ (إذا أجاب خطأ)
- [ ] الشرح يحتوي على **السبب** أو **المعلومة الأساسية**
- [ ] الشرح واضح ومفهوم للطالب
- [ ] لا توجد إجابة بدون شرح (مثل: "✅ صحيح!" فقط)

```javascript
// ❌ خطأ 3: لا توضيح للخطأ
expDiv.textContent = '❌ خطأ - حاول مرة أخرى';

// ❌ خطأ 4: الإشارة للون فقط
expDiv.textContent = '❌ خطأ - الإجابة الصحيحة مظللة باللون الأخضر';
```

---

### **✅ أمثلة صحيحة:**

```javascript
// ✅ صح 1: شرح كامل
expDiv.textContent = '✅ صحيح! قطرا المستطيل متطابقان (متساويان في الطول)، وهذه خاصية تميز المستطيل عن باقي متوازيات الأضلاع';

// ✅ صح 2: توضيح الخطأ
expDiv.textContent = '❌ خطأ. الإجابة الصحيحة هي 720°. لحساب مجموع الزوايا الداخلية نستخدم القانون: (n-2) × 180° = (6-2) × 180° = 720°';

// ✅ صح 3: معلومة إضافية
expDiv.textContent = '✅ صحيح! عثمان بن عفان رضي الله عنه لُقب بذي النورين لأن الرسول ﷺ زوجه ابنتيه: رقية ثم أم كلثوم بعد وفاة رقية';

// ✅ صح 4: شرح مع مقارنة
expDiv.textContent = '❌ خطأ. الفاروق هو لقب عمر بن الخطاب وليس أبو بكر. أما أبو بكر فلقبه الصديق لأنه صدّق النبي ﷺ في حادثة الإسراء والمعراج';
```

### **متى تستخدم الرسوم البيانية؟**

**✅ استخدمها عندما:**
- تُسهّل الفهم بشكل واضح

- الرسم سيكون عشوائياً أو مشوهاً
- لا توجد بيانات حقيقية للمقارنة
- مجرد "ملء مساحة" أو "زينة"

### **🚫 أمثلة على رسومات سيئة يجب تجنبها:**

#### **❌ مثال 1: مربعات متداخلة عشوائية**
```html
<!-- ❌ هذا رسم سيء - مجرد مربعات بلا معنى -->

  <rect x="0" y="0" width="200" height="180" fill="#ef4444" opacity="0.3"/>
  <rect x="20" y="20" width="160" height="140" fill="#f59e0b" opacity="0.3"/>
```

**المشكلة:**
- غير واضح
- لا يوضح معلومة محددة
- مشوه بصرياً
- **حل:** احذفه! استخدم نص بسيط بدلاً منه

## 📐 **قواعد حساب المسافات:**

### **القاعدة 1: نص بجانب خط عمودي**
```
x_نص = x_خط + 30 + (stroke-width / 2)

مثال:
<line x1="150" y1="50" x2="150" y2="300" stroke-width="4"/>
x_نص = 150 + 30 + 2 = 182 (نقرّبها لـ 185)
<text x="185" y="...">النص</text>
```

### **القاعدة 2: نص فوق/تحت خط أفقي**
```
y_نص_فوق = y_خط - 35
y_نص_تحت = y_خط + 35

مثال:
<line x1="50" y1="100" x2="450" y2="100" stroke-width="4"/>
<text x="..." y="65">نص فوق</text>   ← 100 - 35
<text x="..." y="135">نص تحت</text>  ← 100 + 35
```

### **القاعدة 3: نص داخل مستطيل**
```
إذا height < 50px:
  → لا تضع نص داخله!

إذا height ≥ 50px:
  → تأكد: y_نص في منتصف المستطيل
  → تأكد: مسافة 20px من الأعلى والأسفل

مثال:
<rect x="50" y="100" width="200" height="80"/>
y_منتصف = 100 + (80/2) = 140
<text x="150" y="145">النص</text>  ← في المنتصف تماماً
```

### **القاعدة 4: نص خارج شكل بيضاوي**
```
y_نص_فوق = cy - ry - 25
y_نص_تحت = cy + ry + 35

مثال:
<ellipse cx="150" cy="300" rx="50" ry="25"/>
<text x="150" y="250">نص فوق</text>  ← 300 - 25 - 25 = 250
<text x="150" y="335">نص تحت</text>  ← 300 + 25 + 10 (للنص) + 25 = 360
```

### **📐 القاعدة الذهبية لحساب viewBox:**

### **🎯 استخدام text-anchor:**

```html
<!-- للنصوص الوسطى -->
<text x="[منتصف_viewBox]" y="..." text-anchor="middle">نص</text>

<!-- للنصوص اليمنى -->
<text x="[viewBox_width - 100]" y="..." text-anchor="end">نص</text>

<!-- للنصوص اليسرى -->
<text x="80" y="..." text-anchor="start">نص</text>
```

**فائدة:**
- `middle` → النص يتوسط x (آمن!)
- `end` → النص ينتهي عند x (لا يتجاوزه!)
- `start` → النص يبدأ من x

### **✅ قائمة تحقق قبل إغلاق SVG:**

```javascript
// 1. viewBox كافٍ؟
if (أبعد_x + 80 > viewBox_width):
  ❌ كبر viewBox_width

if (أبعد_y + 80 > viewBox_height):
  ❌ كبر viewBox_height

// 2. النصوص داخل الحدود؟
for كل نص:
  عرض_النص = عدد_الأحرف × (font_size / 1.6)
  
  if text-anchor == "middle":
    يسار = x - (عرض_النص / 2)
    يمين = x + (عرض_النص / 2)
  else if text-anchor == "end":
    يسار = x - عرض_النص
    يمين = x
  else: // start
    يسار = x
    يمين = x + عرض_النص
  
  if (يمين > viewBox_width - 80):
    ❌ مشكلة! قلل النص أو كبر viewBox

// 3. المسافات كافية؟
for كل عنصرين:
  if (المسافة < 35px):
    ❌ زد المسافة

// 4. العناصر مرئية؟
for كل عنصر:
  if (x < 50 || y < 50):
    ❌ قريب جداً من الحافة
  if (x > viewBox_width - 100):
    ❌ قريب جداً من اليمين
```

## 🎯 **قواعد ViewBox الدقيقة - تطبيق عملي:**

### **🔴 طريقة حساب viewBox خطوة بخطوة:**

#### **الخطوة 1: قبل كتابة أي SVG - خطط على ورقة**

```
1. ارسم الشكل تقريبياً على ورقة
2. حدد أين ستضع كل عنصر
3. احسب المساحة المطلوبة
4. أضف هوامش 80-100px
```

#### **الخطوة 2: احسب عرض كل نص**

**القاعدة الذهبية:**
```javascript
عرض_النص = عدد_الأحرف × (font_size ÷ 1.5)

أمثلة واقعية:
"النيتروجين 78%" = 14 حرف, font-size=16
عرض = 14 × (16÷1.5) = 14 × 10.6 ≈ 150px

"دورق غير محقون بالهواء" = 23 حرف, font-size=16
عرض = 23 × 10.6 ≈ 245px

"غيوم منخفضة" = 11 حرف, font-size=14
عرض = 11 × 9.3 ≈ 103px
```

#### **الخطوة 3: احسب الموضع الأقصى**

```javascript
// لكل نص، احسب أين ينتهي:

if (text-anchor === "middle") {
  يسار = x - (عرض_النص / 2)
  يمين = x + (عرض_النص / 2)
}
else if (text-anchor === "end") {
  يسار = x - عرض_النص
  يمين = x
}
else { // start
  يسار = x
  يمين = x + عرض_النص
}

// ثم تأكد:
if (يمين > viewBox_width - 100) {
  ❌ مشكلة! النص سيتجاوز الحدود
}
```

#### **الخطوة 4: احسب viewBox النهائي**

```javascript
// اجمع جميع العناصر:
أبعد_x = max(
  آخر_نص_x + عرض_النص,
  آخر_rect_x + width,
  آخر_circle_cx + rx,
  // ... الخ
)

أبعد_y = max(
  آخر_نص_y + 20, // ارتفاع النص تقريباً
  آخر_rect_y + height,
  آخر_circle_cy + ry,
  // ... الخ
)

viewBox_width = أبعد_x + 100  // هامش يمين كبير
viewBox_height = أبعد_y + 80
```

## 📐 **معادلات الحساب السريع:**

### **حساب عرض النص:**
```javascript
function calculateTextWidth(text, fontSize) {
  const arabicChars = text.length;
  const avgWidth = fontSize / 1.5;
  return arabicChars * avgWidth;
}

// أمثلة:
calculateTextWidth("النيتروجين 78%", 16) 
  → 14 × (16/1.5) = 148px

calculateTextWidth("الغيوم المنخفضة", 14) 
  → 15 × (14/1.5) = 140px
```

### **حساب موضع نهاية النص:**
```javascript
function calculateTextEnd(x, textAnchor, textWidth) {
  if (textAnchor === "middle") {
    return x + (textWidth / 2);
  } else if (textAnchor === "end") {
    return x;
  } else { // start
    return x + textWidth;
  }
}

// مثال:
calculateTextEnd(375, "start", 148) 
  → 375 + 148 = 523
```

### **حساب viewBox المطلوب:**
```javascript
function calculateViewBox(elements) {
  let maxX = 0;
  let maxY = 0;
  
  elements.forEach(el => {
    if (el.type === "text") {
      const width = calculateTextWidth(el.text, el.fontSize);
      const endX = calculateTextEnd(el.x, el.textAnchor, width);
      maxX = Math.max(maxX, endX);
      maxY = Math.max(maxY, el.y + 20);
    } else if (el.type === "rect") {
      maxX = Math.max(maxX, el.x + el.width);
      maxY = Math.max(maxY, el.y + el.height);
    }
    // ... الخ
  });
  
  return {
    width: maxX + 100,  // هامش يمين
    height: maxY + 80   // هامش أسفل
  };
}
```
